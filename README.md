# Handover

Centralised login service for VATSIM divisions, built on Laravel and Laravel Passport. Created by [Daniel L.](https://github.com/blt950) (1352906) and [Matan B.](https://github.com/MatanBudimir) (1375048). Special thanks to VATSIM UK, whose open source core system helped us on the right track.

Handover is an OAuth2 provider that sits between VATSIM Connect and your division's services. Members log in once, accept your Data Protection Policy once, and your services use Handover instead of VATSIM Connect directly. Available as a pre-built Docker container.

The project is open source under the GPL-3.0. Read the [LICENSE](LICENSE) for details.
